# RankFlow

O **RankFlow** é um projeto pessoal voltado para programação competitiva, com foco em acompanhamento de desempenho, estatísticas, treinos personalizados e competições entre usuários.

Este repositório está sendo utilizado para o desenvolvimento e organização do projeto, que também serve como forma de praticar e aprofundar conhecimentos em desenvolvimento de software.

A descrição mais detalhada da ideia, funcionalidades, telas, tecnologias e arquitetura planejada está disponível em: [docs/proposta.md](docs/proposta.md)

> 🚧 Projeto em desenvolvimento. A estrutura e as funcionalidades podem sofrer alterações ao longo do tempo.
