# Configuração do Expo

1. Instale Node.js LTS. Para Expo SDK 57, use Node.js 22.13 ou superior.
2. Na raiz do projeto, execute `npm install`.
3. Instale o ngrok globalmente: `npm install -g @expo/ngrok`.
4. Valide com `npx expo-doctor`.
5. Inicie com `npx expo start --tunnel`.

O projeto usa Expo Router e ícones Lucide/SVG.
